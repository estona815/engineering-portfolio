메카트로닉스 전공과 스마트 디스펜서 팀 프로젝트를 바탕으로 장치의 정상·오류·복구 흐름을 설명하고 기록하는 일을 지향합니다. 웹 시뮬레이터와 데이터 검수 시제품 경험을 로봇 운영 절차, 이상 상황 기록, AI 데이터 품질 확인 업무로 연결하고자 합니다.

## 핵심 성과

**전주시 「2026 인구혁신 프로젝트」 시민 정책 제안 공모 최우수상(전주시장상)** · **「J-Shift 90」** · 2026.10.30 발표. 은퇴 숙련 인력·지역 제조·청년 주거를 연결하는 90일 기술정착 정책 제안입니다. [정책 제안 사례](../case-studies/j-shift-90.md)

## 학력·근무 가능 조건

한국폴리텍대학 서울정수캠퍼스 메카트로닉스과 전문학사 과정 · **2027년 2월 졸업예정**. 서울 근무 및 졸업 전 조기취업 가능, 입사일·근무 일정 협의.

## 업무와 연결되는 경험

- 장치 프로젝트: 동작 순서, 정상 배출·걸림·재시도 상태, 시연 절차, 제작 증빙 정리.
- 데이터 검수: 원문과 수정문 대조, 누락·중복·충돌 확인, 검토 상태 및 이벤트 기록.
- 문서·도구: 발표용 웹, 시뮬레이터, GitHub 문서 관리, AI 보조 웹 시제품 제작.

개인·학교 프로젝트에서 쌓은 장치 이해와 기록·검수 경험을 활용하는 신입 지원입니다.

## 주요 프로젝트

### NUTRONICS — 스마트 영양제 디스펜서 | 2026

졸업 팀 프로젝트. 담당 범위는 웹·시뮬레이터·검증 자료·발표 준비입니다.

- 정상 배출, 걸림, 재시도 흐름을 시뮬레이터에서 구분해 보여주고 상태와 이벤트 로그를 확인할 수 있도록 구성했습니다.
- 프로젝트 배경, 팀별 작업, 기구·회로 설명, 제작 증빙을 발표용 웹에 정리했습니다.
- 시뮬레이션 결과를 실제 배출 성공률이나 실물 장치 신뢰성 수치로 대체하지 않습니다.

[사례](../case-studies/nutronics.md) · [소스](https://github.com/estona815/smart-pill-sim-website) · [시뮬레이터](https://estona815.github.io/smart-pill-sim-website/website/simulator.html)

### GlyphCheck · 줄대조 | 2026

한·영 OCR 결과를 원본 영역과 함께 검토하는 시제품입니다.

- 원문·수정문·검토 상태를 연결하고, 내용 변경 시 재검토하도록 하는 흐름을 다룹니다.
- 검토 결과와 원본 식별 정보를 내보내는 구조를 통해 수정 근거를 보존합니다.
- 기존 OCR 모델을 활용하는 프로젝트이며, 자체 모델 학습이나 검증되지 않은 정확도는 주장하지 않습니다.

[사례 및 구현 범위](../case-studies/glyphcheck.md)

### Company Workbench — StockBridge | 2026

AI 보조 구현·검증 자료 정리. CSV의 SKU·지역별 수량 차이, 입력 오류, 충돌 중복을 구분하고 결과를 원본 행까지 추적하는 개인 시제품입니다. 시연용 합성 데이터와 실제 운영 데이터를 구분합니다.

[사례](../case-studies/company-workbench.md) · [소스](https://github.com/estona815/contextpatch-ai-datahub-2026/tree/portfolio/company-workbench-20260929/employer-workbench)
