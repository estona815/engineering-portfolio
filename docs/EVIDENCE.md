# 증거 기준 · 개인 기여 · AI 사용

## 증거를 읽는 방법

1. **주최자 공개 발표**: 이름·작품·등위가 명시된 수상 사실.
2. **계정 연결 커밋**: 연결된 계정이 포함된 특정 변경 범위. 전체 저작·단독 작업·AI와 사람의 작성 비율의 증거는 아님.
3. **저장소 수준 구현**: 고정 commit의 소스·계약·문서. 개인 구현 귀속과 운영 성과는 별도.
4. **체크인 보고서**: 원 저장소가 기록한 수치. 이번 실행 결과나 독립 CI로 표현하지 않음.
5. **과거 로컬 감사**: 해당 날짜와 tree에 한정. 미커밋 변경이 포함된 결과는 다른 SHA에 전용하지 않음.
6. **이번 실행**: 정확한 명령·날짜·소스 hash·결과를 VALIDATION에 기록.

## 개인 기여

기존 2026-08-05 감사는 TuberBot의 계정 연결 커밋 2개와 해당 diff의 부분 기여를 확인했습니다. 다른 검토 프로젝트는 계정 소유만으로 전체 개인 구현을 확정하지 않았습니다. 새로 만든 포트폴리오 커밋은 정리 작업의 증거이며 과거 개발 이력을 소급 생성한 것이 아닙니다. 작성일·커밋일·실행일을 임의로 바꾸지 않습니다.

## AI 사용

Codex 등 AI 도구를 요구사항 분해, 구현, 검증 보조, 문서 작성에 활용합니다. 이 포트폴리오의 정리·코드 발췌·문서는 Codex가 사용자의 요청으로 작성했습니다. 각 프로젝트의 AI disclosure와 원저작권 고지가 우선하며, AI 작성 코드를 사람이 모두 직접 작성했다는 주장을 하지 않습니다. 수상작의 AI 활용 범위는 이 포트폴리오가 소급 추정하지 않습니다.

## 자료 경계

공개 목록은 수집 당시 계정의 공개 저장소만 포함합니다. 비공개 저장소, 내부 로그, raw email, 계약, 접수·지원 데이터, 신분증·통장·학생 증명서, 인증정보는 공개하지 않습니다. 입력 원본과 기존 Git 이력을 보존했습니다. 암호·토큰·개인정보 패턴 검사는 보조 검사이며 공개 권한이나 완전한 비밀 부재를 보증하지 않습니다.

로컬 탐색은 Documents/Desktop/Downloads와 LogicArchiveManager의 명시된 경로에서 깊이를 제한하고 생성·숨김·인증·백업·심볼릭링크·클라우드 동기화 경로를 제외했습니다. 컴퓨터 전체/Drive/숨겨진 과거 기록을 전부 읽거나 백업했다는 의미가 아닙니다. 118개 발견 경로에는 패키지·worktree가 포함됩니다. 파일명으로 발견한 367개 산출물 후보는 전수 내용 검증·업로드되지 않았습니다.
