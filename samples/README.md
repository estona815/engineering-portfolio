# 로컬 개발 코드 발췌

원본을 보존한 코드 발췌입니다.

- `creatorops/publish-policy.ts`: 콘텐츠 hash 승인·QC·권리·공개 승인·feature flag를 검사하는 실제 정책 함수.
- `paper-risk/cost_model.py`: Decimal 기반 비용 계산 도메인. API·계좌·주문 모듈과 분리.
- `instatoon/project-id.ts`: 프로젝트 식별자 처리 유틸리티.

원본과 발췌 SHA-256은 `source-manifest.json`에 기록합니다. 후보자의 단독 저작을 증명하거나 전체 앱의 실행을 보장하는 샘플이 아닙니다. 삭제·게시·금융 주문은 실행하지 않습니다. 새로 부여한 오픈소스 라이선스는 없으며 원저작자와 종속 라이선스가 우선합니다.
